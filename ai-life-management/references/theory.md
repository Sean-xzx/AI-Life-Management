# 三大理论与实际判断

## 阅读定位

本资源解释方法，并提供 A01–A18、K01–K24 的技能覆盖。原文定位与保留边界见 [source-index.md](source-index.md)。不把个人叙述或类比当作普遍因果证据。

## 孙学

访谈以更新认知、先探索、价值创造、机动性与先自由后财富为主要线索。技能将其用于：先明确问题和约束，补充会改变选择的信息，比较机会成本，做有限试验，再按结果调整。思想自由、行动空间和经济自由分开讨论，不推导无资源也能必然成功。

问自己：不知道的是事实还是自己的偏好？哪个假设最值得验证？现在的承诺会限制或支持哪些选择？实际行动改变了什么？这些问题负责改善判断，不能保证财富。

## 薄肌

访谈以身体储备和主动维护支持长期参与。技能关注睡眠、活动、负荷和恢复，把用户实际状态放入日程。用户低精力时不强加健身或生产任务；优先降低当天负担，必要生活责任仍由用户明确。

外观不证明智力、自律或健康。记录与可穿戴数据可能有误差；医学检查和干预需要专业判断。不采用肌肉与心肺各占寿命 25 分、运动方式绝对替代、练了就保证不病等说法。

## 黄毛思维与小 EGO

访谈鼓励不轻易屈从评价，后文又强调小 EGO。技能将自主性与纠错连接：让用户选择目标，帮助检查依据。不同意见中的事实可核查；羞辱不决定目标；反对声不证明嫉妒，也不证明自己正确。

支持坚持有价值的目标，同时允许证据改变手段，甚至让用户修改目标。暂停是一项真实决定，不包装为缺乏意志。记录什么证据会让计划变化，比不断强调相信自己更有用。

## 协同原则与张力

三者的联合作用是提升判断、维持执行条件、支持自主行动并持续纠错。这是本技能的实践整合，非嘉宾提供的成品系统。

| 张力 | 技能中的处理 |
| --- | --- |
| 相信 AI 与人工判断 | AI 提出候选；用户决定目标、权重和外部行动；关键事实核查 |
| 先探索与先行动 | 高成本难撤回的承诺先调查；低成本可逆的小试验尽早做 |
| 机动性与长期深耕 | 保留转换能力，同时计算积累中断的成本 |
| 坚持与开放 | 坚持不等于免于反证；先判断目标还是方法需要改 |
| 认知与现实条件 | 认知影响行动，资源、责任、制度、随机性仍影响结果 |
| 财富与个人意义 | 市场支付只是反馈之一；关系、照护、体验不必须变现 |
| 创造与恢复 | 看实际负担和用户偏好，不指定统一比例 |

## 技能检验问题

判断升级应体现为具体选择或行动不同。检查哪项理解变化、哪项行动变化，以及什么结果将使判断再次改变。不以文档数量、认同程度或使用模型数量代替实际改善。
